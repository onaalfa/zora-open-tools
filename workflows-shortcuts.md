# 10 Workflows d'Automatisation (Raccourcis iOS / macOS)

Cette documentation regroupe 10 architectures de raccourcis conçues pour accélérer la production de contenu, la gestion opérationnelle et l'organisation quotidienne des créateurs et étudiants.

## 1. Redimensionnement Social Media (Batch Resizer)
* **Objectif** : Convertir instantanément une sélection d'images ou de vidéos aux formats 9:16 (TikTok/Reels), 4:5 (Instagram) et 1:1.
* **Fonctionnement** : Récupère les médias depuis la pellicule -> Applique un recadrage intelligent centré -> Exporte dans un album dédié sans perte de qualité.

## 2. Générateur de Prompts Structurés (AI Prompt Builder)
* **Objectif** : Standardiser la création de prompts pour la génération vidéo et d'images.
* **Fonctionnement** : Affiche un menu interactif (Sujet, Cadrage, Lumière, Mouvement de caméra, Style) -> Assemble les variables dans un bloc texte formaté -> Copie automatiquement dans le presse-papiers.

## 3. Mode Studio de Montage (Editing Studio Mode)
* **Objectif** : Préparer l'environnement de travail en un clic avant une session de montage ou de création.
* **Fonctionnement** : Active le mode concentration "Ne pas déranger" -> Règle la luminosité à 80% -> Ouvre successivement les applications de montage et de prise de notes.

## 4. Extraction Audio Rapide (Video to Audio)
* **Objectif** : Extraire la piste sonore d'une vidéo de référence pour l'analyse ou le montage.
* **Fonctionnement** : Prend une vidéo en entrée via le menu de partage -> Encode uniquement le flux audio en M4A/MP3 -> Enregistre dans le dossier Fichiers.

## 5. Capture Vocale vers Notion / Craft
* **Objectif** : Transformer une idée vocale rapide en note structurée.
* **Fonctionnement** : Enregistre l'audio -> Transcrit la voix en texte -> Envoie le texte horodaté directement dans la boîte de réception (Inbox) de l'espace de travail via API.

## 6. Scanner de Reçus & Factures (Ops Expense Tracker)
* **Objectif** : Simplifier le suivi financier et logistique sur le terrain.
* **Fonctionnement** : Ouvre l'appareil photo -> Extrait le texte et le montant via OCR -> Renomme le PDF avec la date du jour et l'archive dans un dossier cloud partagé.

## 7. WhatsApp Direct (Sans contact enregistré)
* **Objectif** : Contacter rapidement un prestataire, un client ou un livreur sans encombrer le carnet d'adresses.
* **Fonctionnement** : Demande la saisie du numéro avec indicatif -> Génère le lien universel `wa.me/` -> Ouvre directement la discussion dans WhatsApp.

## 8. Générateur de QR Code Wi-Fi
* **Objectif** : Partager une connexion réseau lors d'événements, de cours ou de réunions d'équipe.
* **Fonctionnement** : Formate le nom du réseau (SSID) et le mot de passe selon le protocole standard `WIFI:S:...` -> Génère et affiche un QR Code scannable à l'écran.

## 9. Mode Survie Batterie (Ultra Low Power)
* **Objectif** : Maximiser l'autonomie de l'appareil lors des longues journées de tournage ou d'événement.
* **Fonctionnement** : Active l'économie d'énergie -> Baisse la luminosité à 15% -> Coupe l'actualisation en arrière-plan et réduit les effets visuels.

## 10. Briefing Matinal Intelligent (Smart Morning Briefing)
* **Objectif** : Résumer les priorités de la journée dès le réveil.
* **Fonctionnement** : Récupère la météo locale et les événements du calendrier du jour -> Affiche un résumé synthétique des 3 tâches prioritaires à accomplir.
